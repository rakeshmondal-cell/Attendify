PROTOTYPE GUIDE

Try the user journey

  1. Check in using Attendify.
  2. Open My tasks and update or create a task.
  3. Switch to Project Control Web.
  4. Check out from Attendify.
  5. Return to Project Control. Write actions are locked.
  6. Open Reports → Daily to see who checked in and whether PM was updated.
  7. Open Weekly and click Email to manager.
Important rule
Attendance enables eligibility for write access; existing project roles and permissions still apply. Checked-in employees still cannot edit projects they are not authorized for.

Sample data only. No real attendance, project, task, or email records are changed. Alex’s daily report row updates live from this demo session.
